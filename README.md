# Executive Retail Performance Dashboard 📊

This project is a comprehensive Dashboard designed entirely using Microsoft Excel to analyze the sales and profit performance of a retail company.

## 📸 Dashboard Preview:
![Dashboard](لقطة شاشة 2026-08-19 171438.png)

## 🔍 Dashboard Features:
* Sales and profit analysis over time.
* Display of Top Products Returned.
* Heat Map for sales by state.
* Profit analysis by Categories and Customer Segments.
